# Brand

Visual identity for **Awesome DSH Skills**. Everything public — the site, READMEs, badges, share images — uses these tokens. Keep them in sync.

## Mark

A four-point spark on a gradient tile. It reads as *discovery* and *quality* at once and stays legible at 16px.

| Asset | Use |
|:--|:--|
| `docs/brand/mark.svg` | Favicon, avatars, square placements |
| `docs/brand/wordmark-dark.svg` | On dark backgrounds |
| `docs/brand/wordmark-light.svg` | On light backgrounds |
| `docs/brand/banner.svg` | README hero (regenerated daily with live counts) |
| `docs/badge.svg` | “listed on DSH Skills” badge for listed repos |
| `docs/og.png` | Social share image (1200×630) |

## Color

| Token | Value | Role |
|:--|:--|:--|
| `--accent` | `#7c8cff` | Primary — indigo |
| `--accent-2` | `#38d4ff` | Secondary — cyan |
| `--accent-3` | `#c084fc` | Tertiary — violet |
| gradient | `135°, #7c8cff → #38d4ff → #c084fc` | The brand gradient. Only ever this order. |
| `--bg` | `#070a12` | Canvas (dark) |
| `--bg-2` | `#0c1020` | Raised surface (dark) |
| `--text` | `#eef1f8` / `#0f172a` | Primary text (dark / light) |
| `--ok` | `#34d399` | Verified |
| `--warn` | `#fbbf24` | Partial |

## Type

- Display & UI: **Inter** — 800 for headlines, tight tracking (`-0.035em`).
- Numbers & meta: **JetBrains Mono** 500.
- Fallbacks: `-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`.

## Voice

Short. Precise. No hype adjectives. Say what was verified and how; never imply endorsement.
